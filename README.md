# Plop-Wallpaper

Gestionnaire portable de fonds d’écran pour Windows 11 x64. Chaque moniteur dispose de son dossier d’images et de sa propre rotation. L’application est conçue pour fonctionner hors ligne avec une faible consommation de ressources.

Le dépôt est en phase de cadrage. Les instructions de compilation seront ajoutées avec la première version applicative. La [chaîne de compilation x64](docs/adr/ADR-001-chaine-msvc.md) a été vérifiée sur un exécutable de test.
